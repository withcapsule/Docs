Capsule is a lightweight file transfer project for short-lived handoffs: upload a file, share the link or QR code, and the server deletes it automatically after an hour.

- Start with [Getting Started](/guides/getting-started/).
- Use [Web UI](/guides/web/), [Android](/guides/android/), or [CLI](/guides/cli/) for client-specific usage.
- See [API Reference](/api/reference/) for direct integration.
- See [Self-Hosting](/self-hosting/setup/) to run your own instance.
